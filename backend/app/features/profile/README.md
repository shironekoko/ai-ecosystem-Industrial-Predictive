# Profile Feature

โมดูลนี้ใช้สำหรับการจัดการข้อมูลโปรไฟล์ผู้ใช้ รวมถึงรูปอวตาร (Avatar) ประจำตัว

## ระบบนี้ทำอะไรบ้าง
ฟีเจอร์นี้ช่วยให้ผู้ใช้สามารถดูข้อมูลโปรไฟล์ของตัวเอง อัปเดตข้อมูล และอัปโหลดรูปภาพโปรไฟล์ (Avatar) ซึ่งทำงานร่วมกับฟีเจอร์ Storage (MinIO) อย่างแนบเนียน

## API Endpoints
| Path | Method | คำอธิบาย |
| --- | --- | --- |
| `/profile/me` | GET | ดึงข้อมูลโปรไฟล์ของผู้ใช้ปัจจุบัน (ดึงจาก JWT) |
| `/profile/me` | PUT | อัปเดตข้อมูลส่วนตัว |
| `/profile/avatar` | POST | อัปโหลดหรือเปลี่ยนรูป Avatar |

## กระบวนการอัปโหลด Avatar
1. ผู้ใช้ส่งไฟล์รูปภาพผ่าน Endpoint `POST /profile/avatar`
2. ระบบ `Profile Service` ตรวจสอบความถูกต้องของไฟล์
3. ระบบจะส่งต่อไฟล์ให้ `MinIO Client` ในเลเยอร์ Core เพื่ออัปโหลดไปยัง Bucket
4. รับ URL หรือที่อยู่ของไฟล์จาก MinIO กลับมาและอัปเดตลงใน Database ของโปรไฟล์

## การเชื่อมต่อกับ MinIO
- อาศัยคอนฟิก `MINIO_PROFILE_BUCKET` สำหรับเก็บไฟล์ของผู้ใช้
- ไฟล์อวตารจะถูกทำให้อ่านได้อย่างเดียว (Public Read) หรือผ่าน Presigned URL

## ไฟล์ที่เกี่ยวข้อง
- `router.py`: ควบคุมเส้นทาง API ของโปรไฟล์
- `service.py`: ตรรกะในการอัปเดตข้อมูลและจัดการรูปภาพ
- `schemas.py`: Pydantic Models ที่เกี่ยวข้องกับ Profile
- `models.py`: Database schema สำหรับโปรไฟล์ (เชื่อมโยงแบบ One-to-One กับ User)
