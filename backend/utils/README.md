# Utils

โฟลเดอร์ `utils/` เก็บเครื่องมือ (Utilities) และฟังก์ชันตัวช่วย (Helpers) ที่สามารถเรียกใช้งานได้จากทุกๆ ส่วนของระบบ ไม่ยึดติดกับโมดูลฟีเจอร์ใดฟีเจอร์หนึ่ง

## Logger Module
หนึ่งในองค์ประกอบสำคัญในหมวดนี้คือระบบ Logging แบบปรับแต่งได้

- **คำอธิบาย:** ระบบสำหรับบันทึก Log ของระบบ ซึ่งมีการตั้งค่า Format และระดับของ Log ไว้ให้แล้ว
- **วิธีใช้งาน:**
  ```python
  from utils.logger import logger
  
  logger.info("เริ่มต้นการทำงาน")
  logger.error("เกิดข้อผิดพลาดในการเชื่อมต่อ")
  ```

## การตั้งค่า Log File Rotation
- Log จะถูกบันทึกในรูปแบบไฟล์ และมีการจัดการทำ Rotation (หมุนเวียนไฟล์) อัตโนมัติเมื่อขนาดไฟล์เกินที่กำหนด (เช่น ไฟล์ละ 10MB) หรือหมุนเวียนทุกวัน เพื่อป้องกันปัญหาดิสก์เต็ม
- **ตำแหน่งไฟล์:** โฟลเดอร์ `/logs` ของโปรเจกต์ (ขึ้นอยู่กับการตั้งค่า)
