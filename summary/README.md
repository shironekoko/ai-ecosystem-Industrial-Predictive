## ระบบนี้คืออะไร (อธิบายใน 30 วินาที)

ระบบ **Predictive Maintenance ของดอกกัด CNC** ที่ทำงานเป็นวงจรปิดตั้งแต่ "ดอกกำลังตัด" จนถึง "ติดตั้งดอกใหม่" และ "แบบจำลองเรียนรู้จากค่าที่วัดจริง"

1. **ระหว่างตัด (time series)** — ทุกแนวตัดที่จบ แบบจำลอง **GRU direct-RUL** อ่านค่าเซนเซอร์ที่เครื่องบันทึกเอง (แรงตัด, แรงบิด spindle, แรงมอเตอร์แกนป้อน) แล้วบอกว่า **"ดอกนี้ใช้ได้อีกกี่นาที" (RUL)** พร้อมช่วงความเชื่อมั่น P10–P90 และคำแนะนำ OK → WATCH → PLAN_REPLACEMENT → REPLACE_NOW · ถึง REPLACE_NOW ระบบ **หยุดป้อน (interlock)** รอผู้ควบคุมตัดสินใจ
2. **ตอนถอดดอก (non-time-series)** — ระบบถ่ายภาพใบมีด 4 ใบ แบบจำลอง **ensemble 5× ResNet-18** วัด **รอยสึก VB (µm)** ของแต่ละใบ → ระดับดอก = VB เฉลี่ย 4 ใบ เทียบ **เกณฑ์เดียวกับ RUL (103 / 140 µm)** → ผู้ตรวจยอมรับค่า AI หรือวัดจริงแล้วกรอก
3. **หลังตรวจ** — ออก **ใบเบิกดอกทดแทน (PDF)** → รับดอกจากคลัง → ติดตั้ง → เครื่องเริ่มรอบใหม่แบบหยุดชั่วคราวรอผู้ควบคุมกดเริ่มตัด
4. **เรียนรู้ต่อ** — ค่าที่ผู้ตรวจวัดจริงจากดอกใหม่ครบ 6 ดอก (24 ภาพ) → **retrain อัตโนมัติบน GPU** → ผ่าน gate → admin กด promote → ใช้งาน (ทุกเวอร์ชันเก็บใน MinIO สลับกลับได้)

```mermaid
flowchart LR
  S["เซนเซอร์เครื่อง<br/>(LUH .h5 เล่นตามเวลาจริง)"] --> RUL["GRU direct-RUL<br/>RUL + P10–P90 + คำแนะนำ"]
  RUL -->|REPLACE_NOW = interlock| OP{"ผู้ควบคุม"}
  OP -->|ตัดต่อ (override)| S
  OP -->|ถอดดอก| EV["ประเมิน RUL กับ VB จริง<br/>(Reports)"]
  OP -->|ถอดดอก| IMG["ภาพ 4 ใบมีด"] --> VB["ensemble 5× ResNet-18<br/>VB (µm) + P10–P90"]
  VB --> QC{"ผู้ตรวจ"}
  QC -->|ยอมรับค่า AI / กรอกค่าที่วัด| REQ["ใบเบิกดอกทดแทน (PDF)<br/>OPEN → ISSUED → INSTALLED"]
  REQ -->|ติดตั้งดอกใหม่ = รอบใหม่ PAUSED| S
  QC -->|ค่าที่วัดจริง ครบ 6 ดอก| RT["retrain อัตโนมัติ<br/>(ARQ + GPU)"] --> G{"gate + admin"}
  G -->|promote| VB
  MINIO[("MinIO<br/>แบบจำลองทุกเวอร์ชัน · ภาพตรวจ")] -.-> RUL & VB
```

## ตัวเลขที่ควรจำ

| เรื่อง | ค่า |
|---|---|
| เกณฑ์ (ใช้ร่วมกันทั้ง 2 แบบจำลอง) | VB ≥ **140 µm** = หมดอายุ (เกณฑ์เฉพาะงาน) · **103 µm** = เริ่มสึกเร่ง/ใกล้หมดอายุ (จุดเปลี่ยนอัตราสึกที่พบด้วย SETAR) · ระดับดอก = **VB เฉลี่ย 4 คม** |
| ข้อมูล time series | LUH milling: 9 ดอก × 3 เครื่อง, 6,418 แนวตัด (~10 GB .h5) · ฝึก T1,T2,T4,T5,T7,T8 · **สงวน T3/T6/T9** ไว้สตรีมบนเว็บ |
| ข้อมูลภาพ | Nonastreda: 512 ภาพ = 10 ดอก × 10–15 รอบ × 4 ใบมีด · ฝึกดอก 1–6 · val ดอก 7 · **ดอก 8/9/10 = ดอกบนเครื่อง M1/M2/M3** (ไม่เคยใช้ฝึก) |
| RUL — leave-one-tool-out (นาทีของเวลาตัด) | GRU MAE **1.11** (Fleet baseline 1.16, StateSpace 1.58) · พยากรณ์อายุเกินจริง > 1 ชั้นงาน **0%** (StateSpace 13%) |
| RUL — ดอกที่ไม่เคยเห็น T3/T6/T9 | MAE 0.55–2.29 นาที · **เปลี่ยนช้าเกินเกณฑ์ 0/3 ดอก** · สั่งเปลี่ยนก่อนหมดอายุ 3.9–7.0 นาที (ใช้อายุดอก 88–93%) · แจ้งวางแผนล่วงหน้า 9–12 นาที |
| วัด VB จากภาพ | CV ดอก 1–7: MAE **19.6 µm** (v1 22.0) · ดอกทดสอบ 8–10: **24.5 µm** · retrain ในระบบด้วยค่าวัดจริง 24 ใบ (ตัวที่ใช้งาน): ดอก 7 30.7 → 26.2 µm, ดอกที่กันไว้ 13.5 → 7.8 µm · ทาย VB แล้วแปลงเป็นคลาส **ดีกว่า** classifier สูตรเดียวกัน (โซนถูก 69.9% vs 66.8%) และ **เสมอ** กับ classifier ที่จูนแยก (70.5%) |
| ความเร็ว | RUL ~1.6 ms/รัน (numpy, 4,482 พารามิเตอร์/ตัว × 5) · ภาพ ~0.2 s/ภาพบน CPU (5 ตัว) ≈ 1 วินาที/ดอก |
| ระบบ | 43 REST endpoint + 1 WebSocket (ทุกตัวถูกใช้โดยหน้าเว็บ) · 9 หน้าเว็บ · 34 automated test · 7 container (+5 ของชุด observability ที่เปิดเพิ่มได้) |
